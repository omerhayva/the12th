# THE 12TH

**Read the game. Make the call. Prove your football IQ.**

THE 12TH is a live football fan-intelligence platform. Fans make fast tactical decisions during a match; when the real event happens, the platform scores how well they read the game.

## MVP

- Premium responsive live-match interface
- One-tap fan decisions
- Fan Pulse
- Football IQ score breakdown
- Match timeline
- Demo Galatasaray vs Fenerbahçe match
- No betting, gambling or financial rewards
- Built so a real football-data provider can be connected later

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Stack

Next.js + React + TypeScript. The first version intentionally uses local/demo data so product UX can be validated before adding authentication, database, realtime infrastructure and a football API.
